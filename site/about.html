About

An open definition of what makes an agent real.

Not a product pitch — a canonical model, a machine-readable contract, and a runtime anyone can build on.

Why

Most "agents" aren't.

They're a prompt, a workflow, or a tool wrapper — useful, but not accountable. As organizations move agents into production, they need the controls that turn an AI feature into a governed digital worker: identity, authority, decision records, policy, security, and trust.

Real Agent defines that model once, implementation-neutral, so it can be shared across languages, runtimes, and vendors instead of reinvented per framework.

Principles

What this project stands on.

Open & neutral

An open specification (CC BY 4.0) with a vendor-neutral core. No lock-in; databases and frameworks are adapters.

Verifiable

The runtime core is tested and dependency-free; the reference runtime is exercised against a real engine.

Balanced

No single dimension dominates. Governance and security are core, not afterthoughts.

Accountable

Every meaningful step produces an immutable record. Accountability stays with a human owner.

Ecosystem

One piece of a larger platform.

Real Agent is the canonical model and vendor-neutral core. It defines the contract the rest of the AGenNext platform builds on — UIs, marketplaces, and orchestration live in their own repositories.

Marketplace

Providers and integrations come from the MCP registry — not bundled into the core.

Protocols

Communication and context protocols connect agents across teams.

Surfaces

The console, runtime, and platform build on this contract.

Get involved

It's on GitHub.

Read the specification, run the runtime core, open an issue, or contribute. Everything is public.
