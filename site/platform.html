Platform

One model of agency. Implemented, not just described.

A real agent is a graph of twelve primitives bound into one accountable loop — and a runtime that enforces it.

The model

Twelve primitives

Each answers one question. Drop any and you have a tool, a workflow, or an advisor — not an agent.

Identity

Who is acting.

Authority

What it's allowed to do.

Objective

Why it's acting.

Context

What it knows now.

Decision

What it chose.

Action

What it did.

Outcome

What happened.

Memory

What it retained.

Policy

What constrains it.

Trust

How much confidence is justified.

Evaluation

How it's measured.

Governance

Who is accountable.

The loop

Every pass produces a decision record.

  1. Observe
  2. Decide
  3. Authorize
  4. Act
  5. Evaluate
  6. Remember

Objective → Context → Decision → Action → Outcome → Evaluation → Trust → Governance adjustment. The chain is append-only and auditable end to end.

Architecture

Vendor-neutral core, pluggable everything else.

Runtime core

A dependency-free implementation of the contract — no SBOM/supply-chain surface. Governs lifecycle, authority, policy, approval, security, and trust.

Store port

One trait. SurrealDB, or any database, plugs in as an adapter — the core never names a vendor.

Contract

The model as Protobuf, JSON Schema, and a JSON-LD vocabulary — machine-readable and language-neutral.

Reference runtime

A SurrealDB runtime mapping the model onto graph, vector, full-text, and change-feed in one engine.
